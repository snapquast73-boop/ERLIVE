Flagged for Review

This page separates what is implemented and testable from what has not been recovered or independently rechecked. The site is a reconstruction based on the public LIVPBP2 and POSTSSNALRT examples; the original ErrorsLive application and its missing research artifacts are not present in the uploaded repository snapshot (see the audited uploaded source tree). Exact visual or functional parity is therefore unverified.

Values unavailable from an official source are not filled in. The site shows live values only when the browser receives them from MLB's public API; each event card links to its official game feed. The historical official sources specifically noted below were fetched on 2026-11-20; browser CORS and today's live schedule/game responses were not exercised. Direct API links are also provided for manual review.

Implemented in this reconstruction

  • The scoreboard requests the selected date from the public MLB schedule API. Fetched on 2026-11-20, this historical response lists game 775296 as Final, Los Angeles Dodgers 7, New York Yankees 6. That confirms the synthetic scoreboard fixture only; the application pages do not hard-code those historical values (the test fixture is separate).
  • The game and scoring-feed pages request current game data from the official MLB live game feed. Missing values are displayed blank or labeled unavailable rather than inferred.
  • A primary field-error row is selected by the exact result event type field_error, not by matching prose. The official event registry marks that code as a plate-appearance event (baseRunningEvent:false). On 2026-11-20, the linked official MLB play-by-play was fetched: at-bat index 37 is field_error, while index 38 is fielders_choice even though its description mentions a throwing error. This filter does not claim to list every error mentioned in a play.
  • Pending scorer rows include only os_ruling_pending_primary. They exclude os_ruling_pending_prior. The official event-type registry was fetched on 2026-11-20: the primary code is a plate-appearance event, and the prior code is a base-running event; both descriptions read “Official Scorer Ruling Pending.” Synthetic tests guard against treating the prior marker as a primary ruling.
  • Recent feed rows are stored in the current browser's local storage; old rows not reconfirmed by the latest successful scan are labeled as saved copies and excluded from current counts. GitHub Pages serves static files and does not run a repository server; see GitHub's Pages documentation.

Not verified or not implemented — does not block the site

  • Recovered original source: the uploaded README describes research, datasets, a trained model, replay archives, and pages that are absent from this checkout. The README is historical project text, not a verification of those claims. The earlier source audit records that the named upstream was not retrievable at the time; a GitHub API repository lookup cannot establish whether it was private, renamed, or deleted. No model, historic values, or missing pages have been recreated or inferred.
  • Completeness of field-error records: only plays whose result event type is field_error appear in that category. A fielder's-choice result that mentions a throwing error is intentionally not classified as a primary field error. Compare the official play-by-play classifications when reviewing this definition.
  • Review-type labels and scoreboard review banner: the reconstructed interface maps some review types to labels using feed codes/descriptions and reads the schedule's flags.inReview value for its optional banner. Those mappings and the flag's presence in current live schedule responses were not checked against a live MLB response in this restoration. Inspect the official event registry and hydrated schedule before relying on those labels or the banner.
  • Scoring-change history: this browser build does not preserve successive classification snapshots or claim to detect official reclassifications. MLB's separate official scoring-changes page is provided for reference; no scoring-change values are published here.
  • Live browser access and current feeds: tests use synthetic fixtures. Official registry and the historical play-by-play fixture linked above were fetched, but this test run did not exercise browser CORS, today's schedule/game responses, team-logo images, or this commit's public Pages behavior. Those remain unverified here. Manual review links: date-specific MLB schedule, event-type registry, and this project's GitHub Pages site.
